# Security policy

Furina is a client-side browser extension and intentionally requests a small permission set.

If you discover a security issue, please avoid posting sensitive exploit details in a public issue. If GitHub private vulnerability reporting is enabled for the repository, use that channel. Otherwise, contact the maintainer privately through the GitHub profile associated with this repository before publishing details.

Useful reports include:

- Unexpected access outside ClankWorld
- Unsafe handling of user-provided URLs or imported setup data
- Accidental leakage of locally stored Director, continuity, or story information
- Script injection or HTML sanitization problems
- A path that causes Furina to send text or trigger an AI turn without the user's explicit action

Ordinary UI bugs, selector breakage, or layout regressions can be reported through the normal bug template.
